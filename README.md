# KeySwitcher 0.5 for Windows 11

Нативный локальный помощник для русской и английской раскладки. Это Windows-порт концепции open-source проекта [Keyboop](https://github.com/iffuno/keyboop), реализованный на Windows API.

## Что работает

- автоматическое исправление слова на `Space`, `Enter` и `Tab` (`ghbdtn` → `привет`);
- ручное исправление последнего слова: `Ctrl+Alt+Space`;
- включение/выключение автоматики: `Ctrl+Alt+K`;
- двустороннее преобразование EN ↔ RU с сохранением регистра;
- сниппеты из конфигурации;
- исключения по имени `.exe`;
- меню в системном трее и автозапуск с Windows;
- ввод исправления напрямую через Windows `SendInput` — буфер обмена не используется;
- полностью локальная работа, без сети, телеметрии и аккаунтов.
- локальная диктовка Whisper по глобальному хоткею;
- выбор Tiny/Base/Small/Medium и языка распознавания;
- перевод выделенного текста RU ↔ EN через настраиваемый LibreTranslate;
- полноценное тёмное WPF-окно настроек;
- установщик и portable-сборка для Windows 11 x64.

Автоматика специально срабатывает только при уверенном распознавании. Ручной хоткей всегда выполняет физическое преобразование раскладки.

## Сборка актуальной версии

Требуется .NET 8 SDK под Windows.

```powershell
dotnet restore KeySwitcher.sln
dotnet publish KeySwitcher.App/KeySwitcher.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o publish
```

Готовый файл: `publish\KeySwitcher.exe`.

Также включён workflow GitHub Actions: вкладка **Actions → Build Windows 11 → Run workflow**. Результат появится как артефакт `KeySwitcher-Windows-11` с установщиком и portable-версией.

## Настройка

Все параметры доступны в графическом окне. При первом сохранении создаётся файл:

`%LOCALAPPDATA%\by koda\KeySwitcher\settings.json`

Из окна можно настроить хоткеи, модель Whisper, язык, перевод, сниппеты, исключения слов и приложений.

## Голосовой ввод

Хоткей по умолчанию: `Ctrl+Alt+D`. Первое нажатие начинает запись, второе останавливает её и вставляет распознанный текст. Модель Whisper скачивается один раз в `%LOCALAPPDATA%\by koda\KeySwitcher\Models`.

## Перевод

Хоткей по умолчанию: `Ctrl+Alt+T`. Выделите текст в активном поле и нажмите хоткей. По умолчанию приложение обращается только к локальному `http://127.0.0.1:5000`.

Локальный сервер можно запустить отдельно:

```powershell
docker run -d -p 5000:5000 libretranslate/libretranslate
```

## Технические ограничения

- сейчас поддерживается стандартная пара раскладок English US ↔ Russian;
- защищённые поля и приложения, запущенные от администратора, Windows может изолировать от обычного процесса;
- приложение пока не подписано цифровым сертификатом, поэтому SmartScreen может показать предупреждение.

## Приватность

KeySwitcher не сохраняет введённый текст и не содержит аналитики. В памяти хранится только текущее незавершённое слово. Сеть используется лишь для разовой загрузки выбранной модели Whisper и для указанного пользователем сервера перевода; по умолчанию перевод настроен на локальный адрес.
